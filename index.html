About this project

A decision-support prototype

StayMatch is a frontend decision-support prototype built to demonstrate personalized hotel ranking using a weighted-criteria algorithm. All hotel listings, prices, and availability shown here are fictional demo data created for this project — no real bookings are made and no payment is processed.
